# INDIA-GENERAL-ELECTION-RESULTS-ANALYSIS---2024
This repository contains a Power BI dashboard project that presents an in-depth analysis of the India General Election Results 2024. The project highlights key trends, patterns, and insights through four interactive dashboards :- Overview Analysis, State Demographics, Constituency Analysis and State Analysis. 


## 📊 Dashboards Included  

1. **Overview Analysis**  
   - Nation-wide election summary.  
   - Party-wise seat distribution and vote share trends.  

2. **State Demographics**  
   - Voter demographics and their impact on results.  
   - State-level patterns and variations in voting behavior.  

3. **Constituency Analysis**  
   - Detailed breakdown of constituency-level outcomes.  
   - Party-wise votes, winning candidates, runner-up candidates.  

4. **State Analysis**  
   - Comparative state-level insights.  
   - State-wise dominance of political parties and alliances.  

---

## 🌟 Key Features  

- **Interactive Slicers & Filters** – Drill down into specific states, constituencies, and parties.  
- **Charts & Visuals** – Easy-to-read bar charts, pie charts, and maps for deeper insights.  
- **Bookmarks & Page Navigation** – Seamless switching between dashboards.  
- **Party & Candidate Insights** – View party-wise votes, winning/runner-up candidates, and alliances.  
- **Election Summary** – Clear bifurcation of results for quick understanding.
