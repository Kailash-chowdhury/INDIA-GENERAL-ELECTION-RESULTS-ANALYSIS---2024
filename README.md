# INDIA-GENERAL-ELECTION-RESULTS-ANALYSIS---2024
This repository contains a Power BI dashboard project that presents an in-depth analysis of the India General Election Results 2024. The project highlights key trends, patterns, and insights through four interactive dashboards :- Overview Analysis, State Demographics, Constituency Analysis and State Analysis. 


## 📊 Dashboards Included  

1. **Overview Analysis**  
   - High-level summary of overall election outcomes.  
   - Key metrics and trends across the nation.  

2. **State Demographics**  
   - State-level demographic insights.  
   - How demographics influenced voting patterns.  

3. **Constituency Analysis**  
   - Detailed breakdown of results constituency by constituency.  
   - Performance tracking of major parties and candidates.  

4. **State Analysis**  
   - Comparative view of state-level performance.  
   - Trends and patterns across multiple election constituencies.
